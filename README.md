## Perguntas realizadas
1. O que é um agente de IA?
   Um **Agente de Inteligência Artificial** é um sistema que executa tarefas de forma autônoma, projetando e executando fluxos de trabalho com as ferramentas que possui à disposição[1]. Diferente de um modelo de linguagem tradicional, o agente utiliza modelos de linguagem (*LLMs*) como seu núcleo de raciocínio para interpretar comandos, decompor objetivos em subtarefas e decidir quando acionar recursos externos.
   
2. Como funciona um workflow no n8n?
   Um **workflow** (fluxo de trabalho) no n8n é uma sequência de etapas interconectadas que automatiza tarefas de negócios, processa dados e integra diferentes aplicativos e serviços de inteligência artificial[1]. O n8n opera como uma ferramenta de licença *fair-code* focada em unir automação de processos com capacidades de IA.

3. Como integrar modelos de linguagem ao n8n?
   A integração de modelos de linguagem (LLMs) ao n8n une a automação de processos de negócios com o raciocínio agêntico.
